Verlauf

Wird angezeigt, sobald eine Line auf "no" steht oder nicht mehr in der Ausgabe auftaucht.

Router-Logmeldungen

Neue Zeilen aus show logging seit Verbindungsaufbau, rot = Fehler/Warnung (Syslog-Schweregrad 0–4).

Gespeicherte Störungsfälle

Sobald eine Line auf "no" springt oder verschwindet, wird automatisch ein vollständiges show logging vom Router gespeichert (im /data-Volume, übersteht also auch einen Container-Neustart) - zum späteren Nachschauen, was zu dem Zeitpunkt auf dem Router los war.

SIP-Debug (debug ccsip messages)

Läuft über eine eigene, zweite SSH-Sitzung parallel zur Überwachung. Erzeugt bei aktivem Betrieb spürbare Zusatzlast auf dem Router – möglichst zeitnah wieder mit "undebug all" beenden. Der erfasste Log-Text eignet sich zum Einlesen in TranslatorX.

Inaktiv.

Erfasstes Debug-Log

Seit dem Start erfasst, bis zum Stoppen. Zum Weiterverarbeiten in TranslatorX den Inhalt kopieren oder als Datei herunterladen.

Verbindung

Weder Passwort noch Key-Datei angegeben? Dann wird versucht, den SSH-Agenten bzw. die Standard-Keys (~/.ssh) zu verwenden.

Host, Benutzer und weitere Einstellungen werden in config.json auf dem Server gespeichert (Dateirechte 600), damit die Überwachung nach einem Neustart automatisch wieder verbindet. Falls du ein Passwort oder eine Key-Passphrase angibst, wird auch das dort im Klartext gespeichert.
